dsh-mobile · open source

The DeepSeek Harness agent, on your phone.

A mobile host for the DSH ecosystem: a single-threaded QuickJS runtime, a capability gateway, and a pluggable web client — agent sessions with tools, an in-process shell, and authored plugins that live-mount, entirely on-device.

Read the docs Architecture Source

Agent sessions, on-device

Tools, in-process shell (dsh-shell-js), streaming answers — the full spine boots on the phone, no cloud required.

Create with a real LLM

Describe a plugin in chat; the runtime authors it, you approve, and it live-mounts into the running system.

Install & persist

A signed marketplace, install receipts, and restart-safe sessions — state survives force-kills.
